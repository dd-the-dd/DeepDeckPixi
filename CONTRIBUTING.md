# Contributing

Contributions are welcome through pull requests.

1. Branch from `main` and keep rendering independent from hosted-site concerns.
2. Add tests for live replay continuity, closure, decisions or layout changes.
3. Run `npm test`, `npm run lint` and `npm run build`.
4. Update `compatibility.json` when an Engine contract changes.

Direct pushes to protected `main` are disabled. Maintainer review and passing
checks are required before merge.
